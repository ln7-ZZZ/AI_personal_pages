03 / Playbook

协作心得

高质量的结果，不只来自更详细的提示词，也来自合适的协作模式与分工策略。

01

需求清晰，全权交付

对于个性化单词本这类我自己最清楚需求的项目，先把思维导图和具体要求给足，然后完全放手让 TRAE 实现。结果往往比我想的还要完整。

02

各司其职，分工协作

桌宠项目中，后端自己写、框架搭好后前端交给 TRAE。把自己擅长或有特殊想法的部分把握住，把 Agent 更适合的实现工作交出去。

03

善用检索，参考开源

TRAE 能自由上 GitHub 查代码，也能查阅权威文献资料。无论是找类似项目的开源实现，还是整理中医知识库时的原始素材，让 Agent 主动去检索，都比自己一点点翻效率高得多。

04

简单任务直接上手

课程表、概念图这类相对简单的任务，不需要复杂的前置沟通——直接描述目标，TRAE 通常一次就能给出可用版本。

AI Agent 最有价值的地方，不是替你做决定，
而是让你能聚焦于真正重要的那部分。
